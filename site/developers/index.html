Quickstart

Base URL https://kani-api.chatgpt-ai-5-2o2.workers.dev/v1. Send your key as Authorization: Bearer hpk-....

curl https://kani-api.chatgpt-ai-5-2o2.workers.dev/v1/chat/completions \
  -H "Authorization: Bearer $KANI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "kani-otter-4.3", "messages": [{"role": "user", "content": "Write a haiku about otters."}]}'
# pip install openai
import os
from openai import OpenAI

client = OpenAI(base_url="https://kani-api.chatgpt-ai-5-2o2.workers.dev/v1", api_key=os.environ["KANI_API_KEY"])
reply = client.chat.completions.create(
    model="kani-otter-4.3",
    messages=[{"role": "user", "content": "Write a haiku about otters."}],
)
print(reply.choices[0].message.content)
// Node 18+, on your server: never put the key in a web page.
const response = await fetch('https://kani-api.chatgpt-ai-5-2o2.workers.dev/v1/chat/completions', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.KANI_API_KEY}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ model: 'kani-otter-4.3', messages: [{ role: 'user', content: 'Write a haiku about otters.' }] }),
});
const reply = await response.json();
console.log(reply.choices[0].message.content);

Models

ModelGood for
kani-otter-4.3 defaultGeneral chat and writing. Looks things up on the web and on maps, and hands code requests to Cide 2. 88M parameters.
cide-2Code: single-page websites and 19 programming languages. 88M parameters, 2,048-token context.
kani-seal-3Smaller and quicker. 8.7M parameters.

POST /v1/chat/completions

messagesRequired. user and assistant turns, last one from the user, up to 64 messages and 8,000 characters each. system messages are accepted and ignored: Kani has no system prompt.
modelOne of the models above. Default kani-otter-4.3.
max_tokensLongest reply, 1 to 2,048 tokens, within the model's context. Default 512; 2,048 for cide-2. max_completion_tokens works too.
temperature0 to 2. Default 0: the same question gets the same answer. Above 0, Kani samples and the settings below apply.
top_pAbove 0, up to 1. Samples only from the likeliest tokens that together hold this share of the probability. Default 1.
top_k1 to 200. Samples only from this many likeliest tokens. Default 30.
seedA whole number. The same seed and settings give the same sampled reply.
presence_penalty-2 to 2. Above 0 makes Kani less likely to reuse any token it has already written in this reply. Default 0.
frequency_penalty-2 to 2. Like presence_penalty, but stronger for each time a token was used. Default 0.
repetition_penalty1 to 2. Divides the score of tokens already in the reply (the style of Hugging Face and vLLM). Default 1, off.
streamtrue sends the reply as server-sent events, like OpenAI's, ending with data: [DONE].
stream_options{"include_usage": true} sends token counts in one last chunk with no choices, as OpenAI does. Otherwise they come with the finish reason.
stopUp to 4 strings; the reply ends before the first one.
kani_toolsDefault true: Kani searches the web, looks up places and does arithmetic itself. false returns its lookups as text instead (SEARCH: …, PLACES: … @ …) for you to run.

Replies also carry kani.source: model, cide, web, places, local_calculator, local_clock or crisis_support, so you can label answers that came from a helper rather than the model. Penalties and sampling apply to Kani's own replies; summaries of web results stay at temperature 0. user and response_format: {"type": "text"} are accepted and change nothing. Function calling, images, JSON mode, logprobs, logit_bias and n above 1 are not supported.

Errors and limits

401Missing, wrong or deleted key.
400 / 404A request Kani can't take, or an unknown model. The message says which.
429Over 10 requests a minute per key, or 300 a day per account (resets 00:00 UTC). Wait for Retry-After.
502 / 503Kani is waking up or busy. Retry after a few seconds.

Privacy: messages are not stored or logged, only request counts. Keys are stored only as a SHA-256 hash. Web and place lookups send the search words to the search service. Delete a key here to stop it at once.
